## Што такое MCP?

Model Context Protocol (MCP) — гэта адкрыты стандарт, які дазваляе ШІ-асістэнтам падключацца да знешніх крыніц даных і інструментаў. Накіраваўшы MCP-сумяшчальны кліент на наш сервер, ваш ШІ-асістэнт зможа шукаць, атрымліваць і аналізаваць інфармацыю з дакументацыі ER:LC Расія ў рэжыме рэальнага часу.

<Tip>
  **MCP-сервер дае доступ да актуальнай дакументацыі без неабходнасці ўручную капіяваць і ўстаўляць кантэнт у чат ШІ-асістэнта.**
</Tip>

## Падключэнне

### Claude Desktop

Дадайце наступнае ў ваш `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "erlcrussia-wiki": {
      "url": "https://wiki.erlcrussia.com/mcp"
    }
  }
}
```

### Cursor

Дадайце сервер у наладах MCP вашага Cursor:

```json
{
  "mcpServers": {
    "erlcrussia-wiki": {
      "url": "https://wiki.erlcrussia.com/mcp"
    }
  }
}
```

### OpenCode

Дадайце сервер у наладах MCP вашага OpenCode:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "erlcrussia-wiki": {
      "type": "remote",
      "url": "https://wiki.erlcrussia.com/mcp",
      "enabled": true
    }
  }
}
```

### Іншыя Кліенты

Любы кліент, які падтрымлівае аддаленыя MCP-серверы, можа быць накіраваны на пазначаны вышэй URL. Дакладны фармат канфігурацыі глядзіце ў дакументацыі вашага кліента.

## Даступныя Інструменты

Пасля падключэння ваш кліент атрымае доступ да інструментаў для:

* **Пошуку** па дакументацыі па ключавых словах або тэмах
* **Атрымання** канкрэтных старонак і раздзелаў
* **Навігацыі** па структуры дакументацыі

## Навошта гэта выкарыстоўваць?

* Задавайце пытанні свайму ШІ-асістэнту пра нашу дакументацыю і атрымлівайце адказы, заснаваныя на самай актуальнай інфармацыі
* Пазбягайце галюцынацый або састарэлай інфармацыі
* Стварайце агентаў і працоўныя працэсы, якія аўтаматычна сінхранізуюцца са зменамі ў дакументацыі
