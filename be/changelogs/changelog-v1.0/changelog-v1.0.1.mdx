      * **<span style={{ color: '#ff0000' }}>Старая рэдакцыя:</span>** <span style={{ color: '#ff0000' }}>Дазвольце апрацоўку выкліку "Call EMS" перад адраджэннем, пачакайце 2 хвіліны, калі ратавальныя службы не на серверы.</span>
      * **<span style={{ color: '#00be00' }}>Новая рэдакцыя:</span>** <span style={{ color: '#00be00' }}>Пры цяжкім раненні або смерці (з'яўленні плашкі рэспаўна) забаронена адраджацца адразу:</span>
        * <span style={{ color: '#00be00' }}>Калі на серверы ёсць медыкі — абавязкова выклічце хуткую і чакайце 5 хвілін. Калі за гэты час медыкі не прыехалі, дазволена зрабіць рэспаўн, калі прыехалі — працягвайце РП.</span>
        * <span style={{ color: '#00be00' }}>Калі медыкаў на серверы няма — пачакайце 2 хвіліны, пасля чаго дазволены рэспаўн.</span>

    Цалкам уведзены новыя дакументы рэгламенту персаналу ER:LC. Дададзены наступныя старонкі:

    * [**Рэгламент Персаналу ER:LC**](/be/staff/staff-rules/erlc-staff-rules) — дэталёвы рэгламент па абавязках, дысцыпліне, патруляванні і балансе персаналу.
    * [**Правілы Куратара**](/be/staff/staff-rules/curator-rules) — нормы і абавязкі куратараў фракцый.
    * [**Правілы Каманды Прасоўвання**](/be/staff/staff-rules/pr-rules) — рэгламент для PR-каманды і медыя-партнёраў.
    * [**Правы Персаналу**](/be/staff/general/staff-rights) — базавыя правы супрацоўнікаў.
    * [**Этычныя Нормы**](/be/staff/general/ethical-norms) — нормы прафесійнай этыкі.

    * <span style={{ color: '#00be00' }}>Уведзена новая сістэма дысцыпліны: папярэджанні і вымовы аж да аўтаматычнага звальнення, а таксама абавязковы разбор кожнага інцыдэнту.</span>
    * <span style={{ color: '#00be00' }}>Дададзены нормы балансу персаналу і абавязковага патрулявання сервера ў залежнасці ад анлайну.</span>
