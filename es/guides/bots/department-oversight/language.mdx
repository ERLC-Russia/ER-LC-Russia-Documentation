# Selección de Idioma

## ¿Qué es esto?

El bot es totalmente bilingüe: cada comando, botón, mensaje y notificación funciona en **ruso e inglés**. En esta página se define el idioma principal para todo el servidor, determinando cómo ve el personal las respuestas del bot.

Solo necesita configurarlo una vez. Si desea cambiarlo más adelante, regrese a esta sección y elija la otra opción.

## Cómo configurar

1. Ejecute el comando `/configure`.
2. Abra la página **«Selección de Idioma»**.
3. En el menú desplegable **«Seleccione un idioma...»**, elija:
   - **Русский** — interfaz completa del bot en ruso;
   - **English** — interfaz completa del bot en inglés.
4. Listo — el cambio se guarda al instante sin necesidad de reinicio.

<Callout icon="circle-info" color="#3B82F6">
  El idioma afecta exclusivamente a los mensajes del sistema. Los nombres de sus departamentos, rangos y tipos de sanción se conservan tal como los introdujo.
</Callout>

<Callout icon="triangle-exclamation" color="#F59E0B">
  El cambio de idioma aplica a nivel de servidor completo. No se permite establecer idiomas distintos para usuarios individuales.
</Callout>
