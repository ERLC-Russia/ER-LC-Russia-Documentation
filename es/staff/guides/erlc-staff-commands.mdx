<div className="flex justify-center items-center w-full -mt-10">
  <h3 className="text-3xl font-bold">Comandos para Moderación+</h3>
</div>

1. `:tocar` — Permite teletransportarte a tu vehículo. (funciona solo en un coche)
2. `:toatv` — Permite teletransportarte a tu buggy, cortacésped o cuatrimoto. (funciona solo en un vehículo motorizado todoterreno)
3. `:logs` — Permite ver los registros (logs) del servidor.
4. `:kl` — Permite ver la lista de bajas (kill list) en el servidor.
5. `:h` — Permite enviar un anuncio global a todo el servidor.
6. `:pm player` — Permite enviar un mensaje privado a un jugador.
7. `:m` — Permite enviar un mensaje privado a todos los jugadores del servidor.
8. `:tp player` — Permite teletransportar al jugador seleccionado hacia ti.
9. `:tp player(quién) player(hacia quién)` — Permite teletransportar al jugador seleccionado hacia otro jugador.
10. `:bring player` — Permite teletransportar hacia ti al jugador seleccionado.
11. `:to player` — Permite teletransportarte hacia el jugador seleccionado.
12. `:kill player` — Permite eliminar (matar) a un jugador.
13. `:kick player(or id)` — Permite expulsar (kickear) a un jugador del servidor.
14. `:heal player` — Permite restaurar los puntos de vida (HP) de un jugador o revivirlo.
15. `:time 00 - 23` — Permite ajustar la hora del servidor.
    - Por ejemplo: `:time 12` (Ajusta las 12 del mediodía en el mapa)
16. `:wanted player` — Permite colocar nivel de búsqueda (wanted) a un jugador.
17. `:unwanted player` — Permite retirar el nivel de búsqueda a un jugador.
18. `:cmds` — Permite ver la lista de comandos disponibles.
19. `:refresh player` — Permite recargar la apariencia (skin) de un jugador.
20. `:pt number` — Este comando permite activar un modo en el que no se puede causar daño a otros.
    - Por ejemplo: `:pt 60` (crea un modo durante 60 segundos donde nadie puede golpear ni matar)
21. `:prty` — Este comando permite establecer el modo prioritario durante un tiempo determinado.
    - Por ejemplo: `:prty 60` (crea un modo prioritario durante 60 segundos).
22. `:bans` — Este comando permite consultar la lista de baneos.
23. `:helpers` — Este comando permite consultar los ayudantes (helpers) en este servidor.
24. `:mods` — Este comando permite consultar los moderadores en este servidor.
25. `:admins` — Este comando permite consultar los administradores en este servidor.
26. `:startnearfire string` — Este comando permite iniciar un incendio en las proximidades.
    - `:stopdumpsterfire` — Permite extinguir el fuego en un contenedor de basura.
    - `:stopfire string` — Permite detener un incendio.
    - `:starfire string` — Permite iniciar un incendio.

<div className="flex justify-center items-center w-full -mt-14">
  <h3 className="text-3xl font-bold">Comandos para Administración+</h3>
</div>

1. `:loadlayout string` — Comando para el Map Editor. Permite cargar un mapa específico sin necesidad de buscarlo manualmente.
2. `:unloadlayout string` — Comando para el Map Editor. Permite retirar una carga de mapa específica.
3. `:shutdown` — Comando diseñado para reiniciar el servidor. Al ejecutarse, todos los jugadores serán desconectados del servidor.
   <Danger>
     **Este comando solo se puede utilizar con autorización del Propietario.**
   </Danger>
4. `:weather` — Permite activar o desactivar las condiciones climáticas. **Por ejemplo:**
   - `:weather fog` — Genera niebla en el servidor.
   - `:weather snow` — Genera nieve en el servidor.
   - `:weather thunderstorm` — Genera una tormenta eléctrica en el servidor.
   - `:weather rain` — Genera lluvia en el servidor.
   - `:weather clear` — Despeja el clima en el servidor.
5. `:mod player(or id)` — Permite otorgar el rol de "Moderador" a un usuario en el servidor.
6. `:unmod player(or id)` — Permite retirar el rol de "Moderador" a un usuario en el servidor.
7. `:helper player(or id)` — Permite otorgar el rol de "Ayudante" (Helper) a un usuario en el servidor.
8. `:unhelper player(or id)` — Permite retirar el rol de "Ayudante" a un usuario en el servidor.
9. `:ban player(or id)` — Permite banear a un jugador del servidor.
10. `:unban player(or id)` — Permite desbanear a un jugador en el servidor.
