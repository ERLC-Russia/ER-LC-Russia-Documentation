<div className="flex justify-center items-center w-full text-center">
  Abbiamo apportato una lieve modifica alle regole delle fazioni e dei leader. Aggiornati quattro punti relativi al gameplay per evitare situazioni ambigue in futuro.
</div>

***

* **Aggiunti i prefissi alla tabella delle fazioni.**
* **Aggiornata la regola A-8 delle regole dei leader:**
  * **A-8** — "Giorno del Nepotismo": <span style={{ color: '#ff0000' }}>nelle prime 24 ore del loro mandato, un leader può assegnare qualsiasi grado (es. cambiare i capi unità o i delegati).</span> <span style={{ color: '#00be00' }}>Entro le prime</span> **<span style={{ color: '#00be00' }}>24 ore</span>** <span style={{ color: '#00be00' }}>dal momento della nomina all'incarico, il leader ha il diritto di distribuire liberamente qualsiasi grado all'interno della fazione (nominando delegati, capi unità, ecc.).</span>
    * **<span style={{ color: '#00be00' }}>A-8.1</span>** <span style={{ color: '#00be00' }}>— Durante questo periodo, è consentito accettare un numero illimitato di nuovi dipendenti a qualsiasi posizione senza accettazione ufficiale (regola</span> **<span style={{ color: '#00be00' }}>B-7</span>** <span style={{ color: '#00be00' }}>).</span>
    * **<span style={{ color: '#00be00' }}>A-8.2</span>** <span style={{ color: '#00be00' }}>— Per il licenziamento o la retrocessione standard di un giocatore, è comunque richiesta una valida motivazione legale (componente RP (</span>**<span style={{ color: '#00be00' }}>B-7</span>**<span style={{ color: '#00be00' }}>)).</span>
    * **<span style={{ color: '#00be00' }}>A-8.3</span>** <span style={{ color: '#00be00' }}>— Nel "Giorno del Nepotismo", un leader può ricevere un'apposita</span> **<span style={{ color: '#00be00' }}>autorizzazione dal Curatore</span>** <span style={{ color: '#00be00' }}>dell'organizzazione per licenziare i dipendenti senza spiegare le ragioni legali (es. per un azzeramento completo dell'organico a favore di una nuova squadra).</span>
* **Aggiornata la regola B-6:**
  * **B-6** — <span style={{ color: '#ff0000' }}>Motivi per la promozione: superamento con successo del periodo di prova, valutazione positiva/superamento dell'esame, nessuna sanzione disciplinare, meriti speciali, decisione della Direzione.</span> <span style={{ color: '#00be00' }}>La promozione viene concessa esclusivamente per traguardi professionali giustificati (superamento con successo del periodo di prova, valutazione, superamento dell'esame o meriti speciali confermati dai risultati); mentre la formale "decisione della Direzione" non costituisce motivo autonomo per l'avanzamento senza uno specifico contributo del dipendente, e la presenza di un ban esclude del tutto la possibilità di promozione.</span>
* **Aggiornata la regola B-7:**
  * **B-7** — <span style={{ color: '#ff0000' }}>Motivi per retrocessione/licenziamento: violazioni disciplinari, inadempimento sistematico dei doveri, cattiva condotta, dimissioni volontarie, decisione della Direzione.</span> <span style={{ color: '#00be00' }}>Qualsiasi retrocessione forzata o licenziamento deve avere una chiara motivazione legale di gioco, confermata da prove.</span>
    * **<span style={{ color: '#00be00' }}>B-7.1</span>** <span style={{ color: '#00be00' }}>— Un dipendente ha il diritto di lasciare volontariamente la fazione. In tal caso, il licenziamento viene registrato senza la necessità di fornire prove di violazioni.</span>
    * **<span style={{ color: '#00be00' }}>B-7.2</span>** <span style={{ color: '#00be00' }}>— In caso di grave violazione delle regole del server o comportamento inadeguato da parte di un giocatore, la rimozione dall'incarico può essere effettuata su decisione della</span> **<span style={{ color: '#00be00' }}>Direzione o del Curatore</span>** <span style={{ color: '#00be00' }}>della fazione (indipendentemente dalla presenza di ragioni di gioco).</span>
