<div className="flex justify-center items-center w-full text-center">
  Abbiamo effettuato un aggiornamento su larga scala delle regole del server, delle regole delle fazioni e del regolamento dello staff. Le regole su provocazione e respawn sono state chiarite, le norme per le fazioni multiple sono state corrette ed è stato introdotto un regolamento completamente nuovo per lo Staff di ER:LC.
</div>

    * **A-8** — Chiarite le regole sulle provocazioni:
      * **<span style={{ color: '#ff0000' }}>Vecchia versione:</span>** <span style={{ color: '#ff0000' }}>Se una violazione si è verificata a causa della provocazione di qualcuno, la violazione non verrà conteggiata e verrà punito colui che ha provocato.</span>
      * **<span style={{ color: '#00be00' }}>Nuova versione:</span>** <span style={{ color: '#00be00' }}>È vietato cedere alle provocazioni OOC e giustificare le violazioni delle regole del server con motivazioni IC. Se i giocatori hanno ceduto a una provocazione e violato le regole (hanno intrapreso una sparatoria, NRP, insulti OOC, ecc.), la situazione non viene annullata ed entrambe le parti ricevono una sanzione.</span>
        <Callout icon="circle-info" iconType="regular" color="#1a9fff">
          <span style={{ color: '#00be00' }}>**Nota:** Le azioni procedurali lecite dei dipendenti delle strutture governative (controllo documenti, fermi, perquisizioni, ecc.) sono un processo IC a tutti gli effetti e non sono considerate provocazione OOC.</span>
        </Callout>
        <Callout icon="triangle-exclamation" iconType="regular" color="#ff4444">
          <span style={{ color: '#00be00' }}>**Importante:** Se un giocatore ha tentato di provocare una violazione ma la controparte non ha ceduto e ha presentato un reclamo, solo il provocatore riceve la punizione.</span>
        </Callout>

    <div className="flex justify-center items-center w-full -mt-14"><h3 className="text-3xl font-bold"><strong>E. Regole Speciali</strong></h3></div>

    * **E-2** — Chiarite le regole sul respawn:
      * **<span style={{ color: '#ff0000' }}>Vecchia versione:</span>** <span style={{ color: '#ff0000' }}>Consenti l'elaborazione della chiamata "Chiama EMS" prima del respawn, attendi 2 minuti se i servizi di soccorso non sono presenti sul server.</span>
      * **<span style={{ color: '#00be00' }}>Nuova versione:</span>** <span style={{ color: '#00be00' }}>In caso di ferimento grave o morte (quando appare il banner di respawn), è vietato respawnare immediatamente:</span>
        * <span style={{ color: '#00be00' }}>Se i medici sono presenti sul server — devi chiamare un'ambulanza e attendere 5 minuti. Se i medici non arrivano in tempo, il respawn è consentito; se arrivano — continua l'RP.</span>
        * <span style={{ color: '#00be00' }}>Se non ci sono medici sul server — attendi 2 minuti, dopodiché il respawn è consentito.</span>
  </Accordion>

  <Accordion title="Aggiornamento Regole delle Fazioni">
    <div className="flex justify-center items-center w-full -mt-10"><h3 className="text-3xl font-bold"><strong>A. Regole Generali delle Fazioni</strong></h3></div>

    * **A-6.3** — <span style={{ color: '#ff0000' }}>Punto rimosso: "È vietato utilizzare le funzioni ufficiali (database, elenchi dei ricercati, chiamate, segnali speciali, ecc.) per scopi personali, trolling o pressione sui giocatori."</span> Questa norma è stata accorpata in **A-7**.

    <div className="flex justify-center items-center w-full -mt-14"><h3 className="text-3xl font-bold"><strong>B. Fazioni Multiple</strong></h3></div>

    * **B-9** — Corretti i divieti e i permessi per le fazioni multiple:
      * **<span style={{ color: '#ff0000' }}>Rimosso dai divieti:</span>** <span style={{ color: '#ff0000' }}>Governo (IC, Procura, FSO) e qualsiasi altra fazione.</span>
      * **<span style={{ color: '#00be00' }}>Modificato:</span>** <span style={{ color: '#00be00' }}>OPG e Governo (IC, Procura, FSO) → OPG e Governo (IC, Procura, FSO, Tribunale e altri).</span>
      * **<span style={{ color: '#ff0000' }}>Rimosso dalle combinazioni consentite:</span>** <span style={{ color: '#ff0000' }}>FSO e Governo (IC, Procura); FSO e MCHS; FSO e MZ; FSO e Dipartimento dei Trasporti; FSO e FSVNG; FSO e MVD.</span>
  </Accordion>

    * [**Norme Etiche**](/it/staff/general/ethical-norms) — standard di etica professionale.

    <div className="flex justify-center items-center w-full -mt-14"><h3 className="text-3xl font-bold"><strong>Modifiche Principali</strong></h3></div>

    * <span style={{ color: '#00be00' }}>Le regole dello staff sono state **completamente riscritte**: aggiunta la responsabilità per le violazioni dei regolamenti, registrazione obbligatoria dello schermo durante il turno, emissione di tutte le punizioni tramite il bot e rendicontazione per le azioni fuori turno.</span>
    * <span style={{ color: '#00be00' }}>È stato introdotto un nuovo sistema disciplinare: avvertimenti e richiami fino al licenziamento automatico, con processo di revisione obbligatorio per ciascun incidente.</span>
    * <span style={{ color: '#00be00' }}>Aggiunte norme di bilanciamento dello staff e pattugliamento obbligatorio del server in base al numero di utenti online.</span>
