<div className="flex justify-center items-center w-full text-center">
  Abbiamo effettuato un'importante revisione delle regole delle fazioni e dei leader, unificato la terminologia e ottimizzato la struttura della documentazione. I cambiamenti principali riguardano il sistema delle decisioni sul personale, le regole sulle fazioni multiple e il consolidamento delle sezioni specifiche delle fazioni.
</div>

    * **A-4** — Prima di mettere le manette a qualcuno, devi eseguire il roleplay dell'azione.
      * **Esempio:** "Prendo le manette dalla custodia e ti blocco le mani dietro la schiena." \
        **Compiere un'azione senza roleplay nella scena/canale è considerato <span style={{ color: '#ff0000' }}>Fail RP</span><span style={{ color: '#00be00' }}>Non RP</span>.**
    * **A-11** — Ogni giocatore deve essere presente in una scena Discord durante il gioco. Il nickname di Discord deve corrispondere al nome in-game. L'uso di software di modifica della voce o l'ignorare le chiamate nel canale vocale equivale a <span style={{ color: '#ff0000' }}>Fail RP</span><span style={{ color: '#00be00' }}>Non RP</span>.

      * **<span style={{ color: '#00be00' }}>B-7.1 —</span>** <span style={{ color: '#00be00' }}>Il personale di livello superiore viene nominato dal leader di fazione con notifica obbligatoria alla Direzione.</span>

    * **B-9** (in precedenza B-11) — Fazioni multiple e combinazione di posizioni.
      * **B-9.1 —** Un giocatore è tenuto a soddisfare l'intero volume delle quote stabilite in ciascuna delle fazioni prescelte.
      * **È vietato far parte contemporaneamente di queste fazioni:**
        * <span style={{ color: '#ff0000' }}>IC RF e qualsiasi altra fazione.</span>
        * <span style={{ color: '#ff0000' }}>Procura RF e qualsiasi altra fazione.</span>
        * <span style={{ color: '#ff0000' }}>Tribunale e qualsiasi altra fazione.</span>
        * <span style={{ color: '#00be00' }}>Governo (IC, Procura, FSO) e qualsiasi altra fazione.</span>
        * MVD e FSB.
        * OPG e MVD.
        * OPG e FSB.
        * <span style={{ color: '#ff0000' }}>OPG e IC RF.</span>
        * <span style={{ color: '#ff0000' }}>OPG e Tribunale.</span>
        * <span style={{ color: '#ff0000' }}>OPG e Procura RF.</span><span style={{ color: '#00be00' }}>OPG e Governo (IC, Procura, FSO).</span>
        * <span style={{ color: '#ff0000' }}>FSO e OPG.</span>

    <div className="flex justify-center items-center w-full -mt-14"><h3 className="text-3xl font-bold"><strong>C. Disciplina Esecutiva</strong></h3></div>

    * **C-5** — Tutte le ispezioni programmate <span style={{ color: '#00be00' }}>e straordinarie</span> della procura devono essere preventivamente coordinate con il Faction Manager.
    * **C-6.2** — Se un rappresentante della Direzione ha partecipato personalmente al processo, la decisione sulla sua revisione o cancellazione viene presa esclusivamente dall'Alta Direzione (<span style={{ color: '#ff0000' }}>Proprietario e Comproprietari</span><span style={{ color: '#00be00' }}>Proprietario e Leadership del Progetto</span>) <span style={{ color: '#ff0000' }}>Il verdetto dell'Alta Direzione è definitivo e non soggetto ad appello</span><span style={{ color: '#00be00' }}>e la loro decisione non è soggetta ad appello</span>.

    <div className="flex justify-center items-center w-full -mt-14"><h3 className="text-3xl font-bold"><strong>F. Parte Speciale</strong></h3></div>

    * Le sezioni G-M (MVD, FSB, EMERCOM, MoH, Procura, IC, Tribunale) sono state accorpate nella sezione **F. Parte Speciale**.
    * **<span style={{ color: '#00be00' }}>F-1 —</span>** <span style={{ color: '#00be00' }}>Il diritto di condurre ispezioni sulle strutture governative e private appartiene alla Procura. I dipendenti dell'Ufficio del Sindaco sono altresì autorizzati a svolgere attività ispettive per le attività commerciali.</span>
    * **<span style={{ color: '#00be00' }}>F-2 —</span>** <span style={{ color: '#00be00' }}>Non è consentito trattenere ed elaborare un giocatore già morto in una sparatoria e finito in ospedale — è richiesta una nuova situazione IC.</span>
    * **<span style={{ color: '#00be00' }}>F-3 —</span>** <span style={{ color: '#00be00' }}>Su ricorso ufficiale all'FSB (aprendo un ticket sul server FSB) e/o con l'avvio di un procedimento penale, altri dipendenti governativi possono essere fermati o perseguiti dall'FSB.</span>
    * **<span style={{ color: '#00be00' }}>F-4 —</span>** <span style={{ color: '#00be00' }}>La Procura ha il diritto di svolgere attività di vigilanza sulle fazioni governative e sulle organizzazioni private.</span>
    * **<span style={{ color: '#00be00' }}>F-5 —</span>** <span style={{ color: '#00be00' }}>I dipendenti dell'IC sulla scena del crimine dispongono di poteri speciali e hanno il diritto di convocare i dipendenti dell'MVD.</span>
    * **<span style={{ color: '#00be00' }}>F-6 —</span>** <span style={{ color: '#00be00' }}>I dipendenti dell'FSO hanno il diritto di organizzare il lavoro di altri dipartimenti durante le misure di sicurezza.</span>
    * **<span style={{ color: '#00be00' }}>F-7 —</span>** <span style={{ color: '#00be00' }}>Le fazioni hanno il diritto di svolgere altre attività previste dalla legislazione russa che non violino le regole del progetto.</span>
