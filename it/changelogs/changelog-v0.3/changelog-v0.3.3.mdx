      * <span style={{ color: '#00be00' }}>Il roleplay è consentito sia nella "game-chat" del canale Discord dei servizi di emergenza sia nel canale vocale in cui ti trovi (anche se sei da solo al suo interno).</span>
      * <span style={{ color: '#00be00' }}>Quando si utilizza un canale vocale, è obbligatoria una registrazione video in cui le tue parole siano CHIARAMENTE e chiaramente udibili ad alto volume.</span>
      * <span style={{ color: '#00be00' }}>Il roleplay deve essere espresso a voce rigorosamente prima dell'inizio degli spari e deve menzionare il tipo specifico o il nome dell'arma, nonché il fatto di portarla in stato di prontezza al combattimento (dire semplicemente "estratta arma" non è sufficiente).</span>
      * **<span style={{ color: '#00be00' }}>Chiarimento importante:</span>** <span style={{ color: '#00be00' }}></span><span style={{ color: '#00be00' }}>il roleplay è richiesto solo quando si estrae un'arma; quando la si ripone, interpretare l'azione non è obbligatorio.</span>
