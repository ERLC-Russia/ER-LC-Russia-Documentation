# Миграция с ClueControl M

Если ваш сервер раньше работал на боте ClueControl M, этот гайд поможет перенести настройки модулей смен и отпусков в Управление Департаментами. Данные переносятся вручную — займёт 10–15 минут.

<Callout icon="triangle-exclamation" color="#EF4444">
  История смен и статистика автоматически <b>не переносится</b>. Старые данные остаются в базе ClueControl M — учёт времени в новом боте начнётся с нуля.
</Callout>

## Где что находится

В ClueControl M настройки открываются командой `/config` и доступны только Management. В Управлении Департаментами всё в одном меню `/настроить` — до первой настройки его видят администраторы сервера, дальше только [«Роли Настроек»](/ru/guides/bots/department-oversight/permissions).

| Раздел в ClueControl M (`/config`) | Страница в `/настроить` |
| --- | --- |
| Basic Settings | [Настройки Прав](/ru/guides/bots/department-oversight/permissions) |
| Shift Management | [Настройки Смен](/ru/guides/bots/department-oversight/shifts) |
| LOA Requests | [Настройки Отпусков](/ru/guides/bots/department-oversight/loa) |
| RA Requests | [Настройки Отпусков](/ru/guides/bots/department-oversight/loa) + [Пониженная Активность](/ru/guides/bots/department-oversight/ra) |

Роли персонала из **Basic Settings** (Staff / Admin / Management) перенесите на страницу [«Права Доступа»](/ru/guides/bots/department-oversight/permissions) — от них зависит, кто сможет одобрять отпуска и пользоваться админ-командами.

## Смены

Страница [«Настройки Смен»](/ru/guides/bots/department-oversight/shifts):

| В ClueControl M | В Управлении Департаментами |
| --- | --- |
| Toggle «Shift Management» | Статус модуля: «Включен» |
| Shift Channel | Канал логов смен |
| On-Duty Role | Роль на смене |
| More Options → Break Roles | Роль на перерыве |
| More Options → Maximum Staff Online | Лимит Персонала (`0` — без ограничений) |
| More Options → Nickname Prefix | Префикс Ника |
| More Options → Quota | Норма Смены |
| Shift Types | Типы Смен |
| Role Quotas | Квоты Ролей |

<Callout icon="lightbulb" color="#22C55E">
  Формат нормы часов отличается: ClueControl M принимает `1h30m`, новый бот — `60m`, `2h`, `1d`, `1mo`. Пересчитайте значения перед вводом.
</Callout>

Типы смен пересоздаются один в один: название, канал логов типа, роли дежурства, роль перерыва, префикс ника и роли доступа. То же с квотами ролей — создайте их заново через «Квоты Ролей».

### Как перенести типы смен

Чтобы смены работали как раньше, вам нужно перенести типы смен:

1. **В ClueControl M** откройте `/config` → страница **Shift Management** → **Shift Types**.
2. Запишите для каждого типа:
   - **Название** (например: «Патруль», «Офисная работа», «Обучение»)
   - **Канал логов типа** (где падают логи выхода/входа именно этого типа)
   - **Роли на смене** (какие роли получают при выходе на этот тип смены)
   - **Роль перерыва** (если отличается от общей)
   - **Префикс ника** (например: `[ПАТРУЛЬ] `)
   - **Роли доступа** (кто может выбирать этот тип при выходе на смену)
3. **В Управлении Департаментами** зайдите в `/настроить` → **Настройки Смен** → **Типы Смен** → «Создать тип».
4. Заполните поля **строго по записанным данным**:
   - **Название** — то же самое
   - **Канал логов** — выберите тот же канал (или создайте новый, если меняете структуру)
   - **Роли на смене** — добавьте те же роли
   - **Роль перерыва** — укажите, если была
   - **Префикс ника** — скопируйте символ в символ (важно: в ClueControl M префикс ставился **перед** ником, в новом боте так же)
   - **Роли доступа** — выберите те же роли, кто мог использовать этот тип
5. Повторите для каждого типа смены.
6. После создания всех типов проверьте: выйдите на смену тестовым аккаунтом через `/смена управлять` → выберите тип → убедитесь, что выдаются правильные роли, префикс ставится, логи уходят в нужный канал.

<Callout icon="lightbulb" color="#22C55E">
  Если в ClueControl M было много типов смен (5+), создайте их пачкой, а потом пройдитесь по каждому — так быстрее, чем создавать и проверять по одному.
</Callout>

<Callout icon="triangle-exclamation" color="#EF4444">
  **Важно:** В новом боте **роли доступа к типу смены** работают иначе — сотрудник должен иметь **хотя бы одну** из указанных ролей, чтобы тип появился в его списке. В ClueControl M проверка могла быть иной — перепроверьте соответствие.
</Callout>

## Отпуска и ПА

Страница [«Настройки Отпусков»](/ru/guides/bots/department-oversight/loa):

| В ClueControl M | В Управлении Департаментами |
| --- | --- |
| Toggle «LOA Requests» | Приём заявок на отпуск: «Включены» |
| LOA Channel | Канал отпусков |
| LOA Role | Роли отпуска |
| RA Role | Роли ПА ([страница ПА](/ru/guides/bots/department-oversight/ra)) |

Что изменилось по сравнению с ClueControl M:

- **Отдельные переключатели** — приём заявок на отпуск и на ПА включается независимо, а не одним тумблером;
- **Свой канал для ПА** — заявки ПА больше не падают в общий канал отпусков;
- **Фиксированные сроки** — сотрудник выбирает из списка: 1, 3, 7, 14, 21, 30, 60 или 90 дней (вместо свободного формата `s/m/h/d`);
- **Причина отклонения обязательна** — она уходит сотруднику в ЛС;
- **Зачёт ПА** — за время пониженной активности начисляется 50 % отработанного времени;
- Одобрение доступно ролям уровня management из [«Прав Доступа»](/ru/guides/bots/department-oversight/permissions) либо администраторам Discord.

## Отключение модулей в ClueControl M

После настройки Управления Департаментами выключите те же модули в старом боте, чтобы они не работали параллельно. В ClueControl M откройте `/config` и на двух страницах переключите селекты в положение **Disabled**:

- страница **Shift Management** — селект «Shift Management» → Disabled;
- страница **LOA Requests** — селект «LOA Requests» → Disabled.

<Callout icon="lightbulb" color="#22C55E">
  В ClueControl M один тумблер «LOA Requests» управляет сразу и отпусками, и ПА — отдельный переключатель для RA настраивать не нужно.
</Callout>

Пока модуль выключен, команды смен и заявок отвечают сообщением «Not Enabled» — сотрудники перестанут ими пользоваться и полностью перейдут на новый бот.

## Чеклист перехода

1. Выдайте своим руководителям доступ: [«Права Доступа»](/ru/guides/bots/department-oversight/permissions) → «Роли Настроек» и роли управления.
2. [Включите смены](/ru/guides/bots/department-oversight/shifts), укажите канал логов и роль на смене.
3. В «Дополнительных Опциях» задайте роль перерыва, префикс ника, лимит персонала и норму времени (в новом формате).
4. Пересоздайте [типы смен](/ru/guides/bots/department-oversight/shifts) и квоты ролей.
5. Настройте [отпуска](/ru/guides/bots/department-oversight/loa): включите приём заявок, укажите канал и роли отпуска.
6. Настройте [ПА](/ru/guides/bots/department-oversight/ra): отдельный канал и роли.
7. Проверьте, что сотрудники могут выйти на смену через `/смена управлять`, а заявка на отпуск доходит до канала рассмотрения.
8. [Отключите модули](#отключение-модулей-в-cluecontrol-m) в ClueControl M, чтобы они не работали в двух ботах параллельно.
