# Выбор Языка

## Что это такое?

Бот полностью двуязычный: каждая команда, кнопка, сообщение и уведомление работают **на русском и английском**. На этой странице выбирается язык для всего сервера — он применяется ко всем сообщениям бота, которые видят ваши сотрудники.

Выбирать язык нужно один раз. Если позже понадобится сменить язык — просто вернитесь на эту страницу и выберите другой вариант.

## Как настроить

1. Введите команду `/настроить`.
2. Откройте страницу **«Выбор Языка»**.
3. В выпадающем списке **«Выберите язык...»** выберите:
   - **Русский** — весь интерфейс бота на русском языке;
   - **English** — весь интерфейс бота на английском языке.
4. Готово — выбор сохраняется мгновенно, перезапускать ничего не нужно.

<Callout icon="circle-info" color="#3B82F6">
  Язык влияет только на сообщения бота. Названия ваших подразделений, званий и типов наказаний хранятся так, как вы их ввели — их не нужно переводить при смене языка.
</Callout>

<Callout icon="triangle-exclamation" color="#F59E0B">
  Смена языка действует на весь сервер сразу и для всех пользователей. Отдельного языка для каждого сотрудника выбрать нельзя.
</Callout>
