# Настройка Глобального Бана

## Что это такое?

Система единой бан-листы для сети серверов проекта. Команда

```
/глобальный бан @пользователь
```

блокирует нарушителя **сразу на всех связанных серверах**, а не только на текущем. Соответственно `/глобальный разбан` снимает бан по всей сети.

В канал логов уходит подробный отчёт: кто выдал бан, кому и результат по каждому серверу (✅ успешно / ❌ ошибка).

## Как настроить

1. Откройте `/настроить` → страница **«Глобальный Бан»**.
2. Включите модуль: меню статуса → **«Включено»**.
3. В меню **«Разрешённые Роли»** выберите роли команды глобального бана (до 25) — только они смогут выдавать и снимать глобальные bans.
4. Нажмите **«Настроить Сервера»** → **«Добавить Сервер»** и введите **ID сервера** в модальном окне.

### Подтверждение владельцем

Привязка защищена от самопроизвольного добавления чужих серверов:

1. Владелец указанного сервера получает **личное сообщение** от бота «Запрос На Привязку Сервера».
2. Владелец нажимает **«Привязать»** или **«Отклонить»**.
3. До подтверждения сервер помечен как «Ожидает», после — полноценно входит в сеть.

Удаление сервера из сети — кнопкой **«Удалить Сервер»** с выбором из списка. Всего можно связать до **25 серверов**.

***

## Кому доступен глобальный бан

Команда работает **только на основном сервере сети** (хабе). На привязанных серверах она заблокирована для всех — включая их владельцев: бан по всей сети выдаётся централизованно.

На основном сервере команду могут использовать:

- **владелец основного сервера** — всегда;
- **администраторы** — пока не настроены специальные роли;
- участники с ролями из пункта **«Разрешённые Роли»** — после настройки именно они получают исключительный доступ, а права администратора без такой роли больше не действуют.

<Callout icon="triangle-exclamation" color="#EF4444">
  Глобальный бан — крайняя мера. Перед выдачей убедитесь, что нарушение действительно заслуживает блокировки на всех серверах проекта: разбан тоже придётся оформлять через всю сеть.
</Callout>
