# Настройка Объявлений

## Что это такое?

Модуль массовых рассылок между серверами проекта. Вместо того чтобы копировать одно объявление в десятки каналов вручную, руководство отправляет его одной командой:

```
/объявление для департаментов
```

Бот разошлёт пост во все привязанные каналы департаментов (можно дополнительно указать любые другие каналы), при необходимости **с пингом ролей**, а в канал логов отправит отчёт о доставке.

## Как настроить

1. Откройте `/настроить` → страница **«Объявления»**.
2. Включите модуль: меню статуса → **«Включено»**.
3. В меню **«Разрешённые Роли»** выберите, кто может отправлять объявления (до 25 ролей).
4. Выберите **канал логов объявлений** — сюда будут приходить отчёты о каждой рассылке.
5. Нажмите **«Настроить Каналы»** → **«Добавить Канал»** и заполните модальное окно:
   - **«Название»** — имя департамента, например `МВД`;
   - **«Айди Сервера»** — ID сервера, где находится канал департамента;
   - **«Айди Канала»** — ID текстового или анонс-канала для публикаций;
   - **«Айди Ролей через запятую»** — необязательно: роли, которые можно пинговать при объявлении «для всех».

Всего можно привязать до **25 департаментов**.

### Подтверждение владельцем

Если канал находится на чужом сервере, его владельцу придёт ЛС от бота с кнопками **«Подтвердить» / «Отклонить»**. До подтверждения запись помечена как «Ожидает». Свой сервер привязывается сразу.

***

## Как отправить объявление

1. Введите `/объявление для департаментов`.
2. Выберите режим:
   - **«Для всех»** — отправка во все стандартные каналы департаментов (+ опциональный пинг их ролей);
   - ручной ввод — список ID каналов через запятую.
3. Заполните форму: **текст объявления** (до 1700 символов) и по желанию **ссылку на картинку**.
4. Пост публикуется во всех выбранных каналах с подписью автора как глобальное объявление.
5. Отчёт о доставке (куда доставлено, где ошибки) приходит в канал логов.
