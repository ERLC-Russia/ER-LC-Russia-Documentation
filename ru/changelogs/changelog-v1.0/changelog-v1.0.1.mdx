      * <span style={{ color: '#ff0000' }}>**Старая редакция:** Если нарушение произошло из-за провокации кого-либо, нарушение не будет считаться, и наказан будет тот, кто спровоцировал.</span>
      * <span style={{ color: '#00be00' }}>**Новая редакция:** Запрещено поддаваться на OOC-провокации и оправдывать нарушения правил сервера IC-причинами. Если игроки поддались на провокацию и нарушили правила (вступили в перестрелку, NRP, оскорбления в OOC и т.д.), ситуация не откатывается, а наказание получают обе стороны.</span>
        <Callout icon="circle-info" iconType="regular" color="#1a9fff">
          <span style={{ color: '#00be00' }}>**Примечание:** Законные процессуальные действия сотрудников гос. структур (проверка документов, задержание, досмотр и т.д.) являются полноценным IC-процессом и не считаются OOC-провокацией.</span>
        </Callout>
        <Callout icon="triangle-exclamation" iconType="regular" color="#ff4444">
          <span style={{ color: '#00be00' }}>**Важно:** Если игрок попытался спровоцировать на нарушение, но вторая сторона не поддалась и отправила жалобу — наказание получает только провокатор.</span>
        </Callout>

    <div className="flex justify-center items-center w-full -mt-14"><h3 className="text-3xl font-bold"><strong>E. Специальные Правила</strong></h3></div>

    * **E-2** — Уточнены правила респавна:
      * <span style={{ color: '#ff0000' }}>**Старая редакция:** Разрешите обработку вызова "Call EMS" перед возрождением, подождите 2 минуты, если спасательные службы не на сервере.</span>
      * <span style={{ color: '#00be00' }}>**Новая редакция:** При тяжелом ранении или смерти (появлении плашки респавна) запрещено возрождаться сразу:</span>
        * <span style={{ color: '#00be00' }}>Если на сервере есть медики — обязательно вызовите скорую и ждите 5 минут. Если за это время медики не приехали, разрешено сделать респавн, если приехали — продолжайте РП.</span>
        * <span style={{ color: '#00be00' }}>Если медиков на сервере нет — выждите 2 минуты, после чего разрешен респавн.</span>
  </Accordion>

  <Accordion title="Обновление Правил Фракций">
    <div className="flex justify-center items-center w-full -mt-10"><h3 className="text-3xl font-bold"><strong>A. Общие Правила Фракций</strong></h3></div>

    * **A-6.3** — <span style={{ color: '#ff0000' }}>Удалён пункт: «Запрещено использовать служебный функционал (базы данных, розыск, вызовы, спецсигналы и т.п.) для личных целей, троллинга или давления на игроков.»</span> Данная норма объединена с пунктом **A-7**.

    <div className="flex justify-center items-center w-full -mt-14"><h3 className="text-3xl font-bold"><strong>B. Мультифракция</strong></h3></div>

    * **B-9** — Скорректированы запреты и разрешения на совмещение фракций:
      * <span style={{ color: '#ff0000' }}>**Удалено из запрещённых:** Правительство (СК, Прокуратура, ФСО) и любая другая фракция.</span>
      * <span style={{ color: '#00be00' }}>**Изменено:** ОПГ и Правительство (СК, Прокуратура, ФСО) → ОПГ и Правительство (СК, Прокуратура, ФСО, Суд и другие).</span>
      * <span style={{ color: '#ff0000' }}>**Удалено из разрешённых:** ФСО и Правительство (СК, Прокуратура); ФСО и МЧС; ФСО и МЗ; ФСО и Департамент Транспорта; ФСО и ФСВНГ; ФСО и МВД.</span>
  </Accordion>

    * [**Правила Куратора**](/ru/staff/staff-rules/curator-rules) — нормы и обязанности кураторов фракций.
    * [**Правила Команды Продвижения**](/ru/staff/staff-rules/pr-rules) — регламент для PR-команды и медиа-партнёров.
    * [**Права Персонала**](/ru/staff/general/staff-rights) — базовые права сотрудников.
    * [**Этические Нормы**](/ru/staff/general/ethical-norms) — нормы профессиональной этики.

    <div className="flex justify-center items-center w-full -mt-14"><h3 className="text-3xl font-bold"><strong>Ключевые Нормы Нового Регламента</strong></h3></div>

    * **<span style={{ color: '#00be00' }}>C-1.2 — Дисциплинарная лестница:</span>** <span style={{ color: '#00be00' }}>3 варна → Выговор №1; ещё 3 варна → Выговор №2 (временное отстранение); Выговор №3 → Автоматическое увольнение.</span>
    * **<span style={{ color: '#00be00' }}>C-1.3 — Экстренные меры:</span>** <span style={{ color: '#00be00' }}>Менеджмент вправе выдать выговор сразу, минуя варны, при грубом проступке.</span>
    * **<span style={{ color: '#00be00' }}>D-1.1 — Баланс персонала:</span>** <span style={{ color: '#00be00' }}>Введена таблица нормативов распределения сотрудников в зависимости от онлайна (2–10, 10–15, 15–20, 20–30, 30–39 игроков).</span>
    * **<span style={{ color: '#00be00' }}>D-1.3 — Патруль:</span>** <span style={{ color: '#00be00' }}>Каждый сотрудник обязан выезжать в патруль каждые 5–10 минут при отсутствии тикетов.</span>
    * **<span style={{ color: '#00be00' }}>A-1.13 — Мод-права для игровых привилегий:</span>** <span style={{ color: '#00be00' }}>Запрещено использовать права модератора для получения запрещённых транспортных средств, оружия или иных игровых возможностей, недоступных обычным игрокам.</span>
