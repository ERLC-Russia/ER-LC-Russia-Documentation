# Language Selection

## What is This?

The bot is fully bilingual: every command, button, message, and notification operates in **Russian and English**. On this page, you select the primary language for the entire server — it applies to all messages your staff see.

You only need to select the language once. If you ever need to change it later, simply return to this page and select another option.

## How to Configure

1. Run the `/configure` command.
2. Open the **“Language Selection”** page.
3. In the **“Select language...”** dropdown, choose:
   - **Русский** — entire bot interface in Russian;
   - **English** — entire bot interface in English.
4. Done — the selection is saved immediately; no restart is required.

<Callout icon="circle-info" color="#3B82F6">
  The language setting only affects the bot's system messages. Names of your departments, ranks, and punishment types are stored exactly as you enter them and do not need translation when switching languages.
</Callout>

<Callout icon="triangle-exclamation" color="#F59E0B">
  Language changes apply across the entire server for all users. Setting different languages per individual user is not supported.
</Callout>
