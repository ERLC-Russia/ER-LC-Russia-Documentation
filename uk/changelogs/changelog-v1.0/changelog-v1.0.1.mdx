<AccordionGroup>
  <Accordion title="Оновлення Правил Сервера">
    <div className="flex justify-center items-center w-full -mt-10"><h3 className="text-3xl font-bold"><strong>A. Основні Правила</strong></h3></div>

    * **A-8** — Уточнено правила провокацій:
      * **<span style={{ color: '#ff0000' }}>Стара редакція:</span>** <span style={{ color: '#ff0000' }}>Якщо порушення сталося через провокацію когось, порушення не зараховуватиметься, і покараний буде той, хто спровокував.</span>
      * **<span style={{ color: '#00be00' }}>Нова редакція:</span>** <span style={{ color: '#00be00' }}>Заборонено піддаватися на OOC-провокації та виправдовувати порушення правил сервера IC-причинами. Якщо гравці піддалися на провокацію і порушили правила (вступили в перестрілку, NRP, образи в OOC тощо), ситуація не відкочується, а покарання отримують обидві сторони.</span>
        <Callout icon="circle-info" iconType="regular" color="#1a9fff">
          <span style={{ color: '#00be00' }}>**Примітка:** Законні процесуальні дії співробітників держ. структур (перевірка документів, затримання, огляд тощо) є повноцінним IC-процесом і не вважаються OOC-провокацією.</span>
        </Callout>
        <Callout icon="triangle-exclamation" iconType="regular" color="#ff4444">
          <span style={{ color: '#00be00' }}>**Важливо:** Якщо гравець спробував спровокувати на порушення, але друга сторона не піддалася і надіслала скаргу — покарання отримує тільки провокатор.</span>
        </Callout>

    <div className="flex justify-center items-center w-full -mt-14"><h3 className="text-3xl font-bold"><strong>E. Спеціальні Правила</strong></h3></div>

    * **E-2** — Уточнено правила респавну:
      * **<span style={{ color: '#ff0000' }}>Стара редакція:</span>** <span style={{ color: '#ff0000' }}>Дозвольте обробку виклику "Call EMS" перед відродженням, зачекайте 2 хвилини, якщо рятувальні служби не на сервері.</span>
      * **<span style={{ color: '#00be00' }}>Нова редакція:</span>** <span style={{ color: '#00be00' }}>При тяжкому пораненні або смерті (появі плашки респавну) заборонено відроджуватися відразу:</span>
        * <span style={{ color: '#00be00' }}>Якщо на сервері є медики — обов'язково викличте швидку і чекайте 5 хвилин. Якщо за цей час медики не приїхали, дозволено зробити респавн, якщо приїхали — продовжуйте РП.</span>
        * <span style={{ color: '#00be00' }}>Якщо медиків на сервері немає — вичекайте 2 хвилини, після чого дозволено респавн.</span>
  </Accordion>

  <Accordion title="Оновлення Правил Фракцій">
    <div className="flex justify-center items-center w-full -mt-10"><h3 className="text-3xl font-bold"><strong>A. Загальні Правила Фракцій</strong></h3></div>

    * **A-6.3** — <span style={{ color: '#ff0000' }}>Видалено пункт: «Заборонено використовувати службовий функціонал (бази даних, розшук, виклики, спецсигнали тощо) для особистих цілей, тролінгу або тиску на гравців.»</span> Цю норму об'єднано з пунктом **A-7**.

    <div className="flex justify-center items-center w-full -mt-14"><h3 className="text-3xl font-bold"><strong>B. Мультифракція</strong></h3></div>

    * **B-9** — Скориговано заборони та дозволи на суміщення фракцій:
      * **<span style={{ color: '#ff0000' }}>Видалено із заборонених:</span>** <span style={{ color: '#ff0000' }}>Уряд (СК, Прокуратура, ФСО) та будь-яка інша фракція.</span>
      * **<span style={{ color: '#00be00' }}>Змінено:</span>** <span style={{ color: '#00be00' }}>ОЗУ та Уряд (СК, Прокуратура, ФСО) → ОЗУ та Уряд (СК, Прокуратура, ФСО, Суд та інші).</span>
      * **<span style={{ color: '#ff0000' }}>Видалено з дозволених:</span>** <span style={{ color: '#ff0000' }}>ФСО та Уряд (СК, Прокуратура); ФСО та МНС; ФСО та МОЗ; ФСО та Департамент Транспорту; ФСО та ФСВНГ; ФСО та МВС.</span>
  </Accordion>

  <Accordion title="Нові Правила Персоналу ER:LC">
    <div className="flex justify-center items-center w-full -mt-10"><h3 className="text-3xl font-bold"><strong>Регламент Персоналу</strong></h3></div>

    Повністю введено нові документи регламенту персоналу ER:LC. Додано такі сторінки:

    * [**Регламент Персоналу ER:LC**](/uk/staff/staff-rules/erlc-staff-rules) — детальний регламент щодо обов'язків, дисципліни, патрулювання та балансу персоналу.
    * [**Правила Куратора**](/uk/staff/staff-rules/curator-rules) — норми та обов'язки кураторів фракцій.
    * [**Правила Команди Просування**](/uk/staff/staff-rules/pr-rules) — регламент для PR-команди та медіа-партнерів.
    * [**Права Персоналу**](/uk/staff/general/staff-rights) — базові права співробітників.
    * [**Етичні Норми**](/uk/staff/general/ethical-norms) — норми професійної етики.

    <div className="flex justify-center items-center w-full -mt-14"><h3 className="text-3xl font-bold"><strong>Головні Зміни</strong></h3></div>

    * <span style={{ color: '#00be00' }}>Правила персоналу **повністю переписані**: додано відповідальність за порушення регламенту, обов'язковий запис екрана на зміні, оформлення всіх покарань через бота та звітність за дії поза зміною.</span>
    * <span style={{ color: '#00be00' }}>Введено нову систему дисципліни: попередження та догани аж до автоматичного звільнення, а також обов'язковий розгляд кожного інциденту.</span>
    * <span style={{ color: '#00be00' }}>Додано норми балансу персоналу та обов'язкового патрулювання сервера залежно від онлайну.</span>
  </Accordion>
