      * **B-9.1 —** Гравець зобов'язаний виконувати повний обсяг встановлених квот (норму змін/звітів) у кожній з обраних фракцій.
      * **Заборонено перебувати в цих фракціях одночасно:**
        * <span style={{ color: '#00be00' }}>Уряд (СК, Прокуратура, ФСО) та будь-яка інша фракція.</span>
        * МВС та ФСБ.
        * ОЗУ та МВС.
        * ОЗУ та ФСБ.
        * <span style={{ color: '#00be00' }}>ОЗУ та Уряд (СК, Прокуратура, ФСО).</span>

    <div className="flex justify-center items-center w-full -mt-14"><h3 className="text-3xl font-bold"><strong>C. Виконавча Дисципліна</strong></h3></div>

    * **C-5** — Усі планові <span style={{ color: '#00be00' }}>та позапланові</span> перевірки прокуратури мають бути заздалегідь узгоджені з Менеджером Фракцій.
    * **C-6.2** — Якщо представник Менеджменту особисто брав участь у процесі, рішення про його перегляд чи скасування приймається виключно Вищим менеджментом (<span style={{ color: '#00be00' }}>Власником та Керівництвом</span>) <span style={{ color: '#00be00' }}>і їхнє рішення вже не підлягає оскарженню</span>.

    <div className="flex justify-center items-center w-full -mt-14"><h3 className="text-3xl font-bold"><strong>F. Особлива Частина</strong></h3></div>

    * Розділи G-M (МВС, ФСБ, МНС, МОЗ, Прокуратура, СК, Суд) об'єднані в розділ **F. Особлива Частина**.
    * **<span style={{ color: '#00be00' }}>F-1 —</span>** <span style={{ color: '#00be00' }}>Право на проведення перевірок діяльності державних та приватних структур мають органи Прокуратури. Щодо приватних організацій (бізнесу) повноваженнями щодо здійснення перевірочних заходів також наділяються співробітники Мерії.</span>
    * **<span style={{ color: '#00be00' }}>F-2 —</span>** <span style={{ color: '#00be00' }}>Не можна затримувати та дооформлювати гравця, який уже помер під час перестрілки та опинився в лікарні — потрібна нова IC-ситуація.</span>
    * **<span style={{ color: '#00be00' }}>F-3 —</span>** <span style={{ color: '#00be00' }}>За фактом офіційного звернення до органів ФСБ (подання тікета на сервері ФСБ) та/або порушення кримінальної справи інші співробітники державних структур РФ можуть бути затримані або притягнуті до відповідальності органами ФСБ, за участю слідчих та подальших процедур судо- та діловодства.</span>
    * **<span style={{ color: '#00be00' }}>F-4 —</span>** <span style={{ color: '#00be00' }}>Прокуратура РФ має право здійснювати наглядову діяльність щодо державних фракцій та приватних організацій.</span>
    * **<span style={{ color: '#00be00' }}>F-5 —</span>** <span style={{ color: '#00be00' }}>Співробітники СК на місці злочину мають особливі повноваження і мають право викликати співробітників МВС.</span>
    * **<span style={{ color: '#00be00' }}>F-6 —</span>** <span style={{ color: '#00be00' }}>Співробітники ФСО мають право організовувати роботу інших відомств під час здійснення охоронних заходів об'єкта.</span>
    * **<span style={{ color: '#00be00' }}>F-7 —</span>** <span style={{ color: '#00be00' }}>Фракції мають права на здійснення й іншої діяльності, передбаченої законодавством РФ, але яка не порушує правила проєкту.</span>
