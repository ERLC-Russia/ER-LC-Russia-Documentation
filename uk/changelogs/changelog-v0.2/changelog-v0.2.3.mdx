* **Оновлення пункту A-8 правил лідерів:**
  * **A-8** — «День блату»: У перші 24 години з моменту призначення на посаду, лідер має право вільно розподіляти будь-які ранги всередині фракції (призначення заступників, керівників підрозділів тощо).
    * **A-8.1** — У цей період дозволяється приймати необмежену кількість нових співробітників на будь-які посади без офіційного прийняття (**правило** **B-7**).
    * **<span style={{ color: '#00be00' }}>A-8.2</span>** — <span style={{ color: '#00be00' }}>У «День блату» лідер має право вільно понижувати та підвищувати будь-яких співробітників на посаді без пояснення причин. Однак для звільнення гравця, як і раніше, потрібна вагома законна причина (РП-причина).</span>
    * **<span style={{ color: '#00be00' }}>A-8.3</span>** — <span style={{ color: '#00be00' }}>Лідер може отримати спеціальний дозвіл від Куратора на звільнення співробітників без пояснення причин (наприклад, для повного розчищення складу).</span>
