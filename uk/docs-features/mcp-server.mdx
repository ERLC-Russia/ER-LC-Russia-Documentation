## Що таке MCP?

Model Context Protocol (MCP) — це відкритий стандарт, що дозволяє ШІ-асистентам підключатися до зовнішніх джерел даних та інструментів. Спрямувавши MCP-сумісний клієнт на наш сервер, ваш ШІ-асистент зможе шукати, отримувати та аналізувати інформацію з документації ER:LC Росія в режимі реального часу.

<Tip>
  **MCP-сервер надає доступ до актуальної документації без необхідності вручну копіювати та вставляти контент у чат ШІ-асистента.**
</Tip>

## Підключення

### Claude Desktop

Додайте наступне до вашого `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "erlcrussia-wiki": {
      "url": "https://wiki.erlcrussia.com/mcp"
    }
  }
}
```

### Cursor

Додайте сервер у налаштуваннях MCP вашого Cursor:

```json
{
  "mcpServers": {
    "erlcrussia-wiki": {
      "url": "https://wiki.erlcrussia.com/mcp"
    }
  }
}
```

### OpenCode

Додайте сервер у налаштуваннях MCP вашого OpenCode:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "erlcrussia-wiki": {
      "type": "remote",
      "url": "https://wiki.erlcrussia.com/mcp",
      "enabled": true
    }
  }
}
```

### Інші Клієнти

Будь-який клієнт, що підтримує віддалені MCP-сервери, може бути спрямований на вказаний вище URL. Точний формат конфігурації дивіться в документації вашого клієнта.

## Доступні Інструменти

Після підключення ваш клієнт отримає доступ до інструментів для:

* **Пошуку** по документації за ключовими словами або темами
* **Отримання** конкретних сторінок і розділів
* **Навігації** по структурі документації

## Навіщо це використовувати?

* Ставте запитання своєму ШІ-асистенту про нашу документацію та отримуйте відповіді, що ґрунтуються на найактуальнішій інформації
* Уникайте галюцинацій або застарілої інформації
* Створюйте агентів і робочі процеси, які автоматично синхронізуються зі змінами в документації
