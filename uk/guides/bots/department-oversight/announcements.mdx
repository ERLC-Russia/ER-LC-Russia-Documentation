# Налаштування Оголошень

## Що це таке?

Система масових розсилок по серверах мережі. Замість ручного копіювання тексту по десятках каналів, керівництво надсилає новину однією командою:

```
/announcement for departments
```

Бот розсилає публікацію в усі прив'язані канали департаментів (плюс за потреби у вказані ID каналів), опціонально **пінгує задані ролі** та надсилає звіт про доставку в канал логів.

## Як налаштувати

1. Відкрийте `/configure` → сторінка **«Оголошення»**.
2. Увімкніть модуль: статус → **«Увімкнено»**.
3. У **«Дозволені Ролі»** виберіть, хто може робити розсилки (до 25 ролей).
4. Оберіть **канал логів оголошень** для звітів.
5. Натисніть **«Налаштувати Канали»** → **«Додати Канал»** і вкажіть:
   - **«Назва»** — назва департаменту (наприклад, `МВС`);
   - **«ID гільдії (сервера)»** — ID сервера, де знаходиться канал;
   - **«ID каналу»** — ID текстового каналу для публікацій;
   - **«ID ролей через кому»** — ролі для пінгу під час загальних розсилок.

Можна підключити до **25 департаментів**.

### Підтвердження власником сервера

Якщо канал знаходиться на чужому сервері, його власник отримає повідомлення в ПП від бота з кнопками **«Підтвердити» / «Відхилити»**. До підтвердження канал перебуває в статусі «Очікує». Канали власного сервера прив'язуються одразу.

***

## Як надіслати оголошення

1. Виконайте команду `/announcement for departments`.
2. Оберіть режим розсилки:
   - **«Для всіх»** — у всі стандартні канали департаментів (+ пінг ролей);
   - введення списку ID каналів через кому.
3. Заповніть форму: **текст оголошення** (до 1700 символів) та опціонально **URL зображення**.
4. Повідомлення публікується в усіх каналах із підписом автора.
5. У канал логів надходить повний звіт про статус доставки.
